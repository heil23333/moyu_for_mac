# 摸鱼 PDF 阅读器 🐟

> 一款为摸鱼场景设计的极简 PDF 阅读器。**没有标题栏，没有按钮，没有边框** — 只有内容和右键菜单。

## 功能特性

| 功能 | 说明 |
|------|------|
| **极简外观** | 无边框、无标题栏、无按钮，纯内容显示 |
| **透明度调节** | 10% ~ 100%，右键菜单选择或快捷键微调 |
| **窗口置顶** | 默认置顶，可随时切换 |
| **页面裁剪** | 自动去除白边，最大化显示内容 |
| **无限滚动** | 所有页面纵向连续排列 |
| **拖拽打开** | 直接拖拽 PDF 文件到窗口 |

## 操作方式

### 右键菜单（主要操作方式）

在窗口任意位置 **右键** 即可弹出菜单：

```
📂 打开 PDF
───────────────
✂️ 裁剪: 开/关
📌 置顶: 开/关
👁️ 透明度 → 30% / 40% / 50% / 60% / 70% / 80% / 90% / 100%
───────────────
💾 保存当前可见页
───────────────
─ 最小化
✕ 退出
```

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + O` | 打开文件 |
| `Ctrl + C` | 切换裁剪模式 |
| `Ctrl + T` | 切换窗口置顶 |
| `Ctrl + =` | 增加透明度 |
| `Ctrl + -` | 减小透明度 |
| `Ctrl + 0` | 恢复不透明 |
| `Ctrl + Q` / `Esc` | 退出 |
| `Ctrl + 滚轮` | 快速调节透明度 |

### 移动窗口

**左键拖拽**窗口任意位置即可移动。

## 快速启动

### 方式一：双击启动

双击 `launch.command` 文件即可启动。

### 方式二：命令行

```bash
cd /Users/li/AgentWorkspace/moyu
./launch.command [你的文件.pdf]
```

### 方式三：直接运行

```bash
/Users/li/.workbuddy/binaries/python/envs/moyu-pdf/bin/python3 moyu_pdf.py [你的文件.pdf]
```

## 调透明度的小技巧

- **右键 → 透明度**：一键选择预设值
- **Ctrl + 鼠标滚轮**：快速微调
- 建议 **50%~70%**，配合浅色桌面效果最佳
